# 源表字段总字典

更新时间：2026-07-01

用途：保存当前项目根目录下可复用表格的字段快照，后续做导入、写回、页面字段展示和业务对齐时先查这里。

抽取规则：

- 只扫描项目根目录的 `.xlsx` 源表，不扫描 `outputs/` 里的生成结果。
- 直接解析 `.xlsx` 内部 XML，避免在线表导出的 workbook 维度不准。
- 只保留候选表头行，不保存历史商品样例数据。
- 记录的是当前文件快照；实现时仍应按表头名称匹配，不要只写死列号。
- 多行表头按行保存，例如中央新品表通常第 1 行是分组、第 2 行是字段。
- 两张认领反馈表的字段漂移详表见 `docs/16-新品认领反馈源表实测字段清单.md`。

## 3. 复用约定

- 新导入器优先用字段名匹配，字段名相同但列号漂移时按字段名继续解析。
- 平台目标字段字典以 `东南亚海外仓新品表-PH/TH/VN` 为准；导入、展示、认领、复核和导出都优先对齐中央表字段。
- 来源表有但中央表没有的字段作为来源扩展字段保留；中央表有但来源表没有、且无法通过唯一匹配补全的字段默认空值，不用 `0`。
- `站点` / `国家` 优先读行内字段；只有源表确实没有该字段时，才走导入批次人工选择或业务确认。
- 写回中央新品表时，目标列按表头匹配，例如 `销售员1`、`预估单销`，不要写死 CD/CE 等列号。
- 无法唯一匹配的记录第一版不自动写回、不生成异常清单；导出不受影响，外部在线表由人工处理。
