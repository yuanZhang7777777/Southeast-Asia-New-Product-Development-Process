# 图片拖拽与粘贴上传设计

> 确认日期：2026-07-17
> 适用范围：运营认领、二次调研

## 1. 目标

所有调研图片入口统一支持三种方式：

- 点击选择一张或多张图片。
- 将一张或多张图片拖入当前子 SKU 的图片区域。
- 在当前子 SKU 的图片区域或“调研结论”输入框按 `Ctrl+V` 粘贴剪贴板图片。

## 2. 已确认交互

- 图片始终上传到当前操作行对应的子 SKU，不使用页面级粘贴监听。
- 在“调研结论”中粘贴的内容同时包含文字和图片时，文字照常进入结论，图片同时自动上传。
- 一次可处理多张图片；非图片文件直接忽略，不发起上传。
- 继续沿用现有单张图片不超过 8MB 的后端校验、上传接口、OSS/本地兜底、缩略图和大图预览。
- 图片上传成功后沿用当前业务保存行为；失败时保留当前文字和其他已填内容，并显示上传失败提示。

## 3. 实现边界

- 运营认领：保留现有图片区域的选择、拖拽和粘贴能力，并给列表输入框、详情输入框中的“调研结论”补充图片粘贴。
- 二次调研：给图片区域补充拖拽和粘贴，并给 `AN 调研结论` 补充图片粘贴。
- 复用现有 `POST /claims/evidence-images`，不新增后端接口、数据库字段或第三方依赖。
- 不监听页面全局剪贴板事件，避免图片被上传到错误的子 SKU。

## 4. 验收标准

1. 两个业务页面的图片区域均可选择、拖入和粘贴多张图片。
2. 两个业务页面在当前行“调研结论”粘贴图片后，图片出现在同一行缩略图列表。
3. 混合粘贴不会丢失文字，也不会覆盖上传期间发生的其他输入修改。
4. 非图片文件不会发起图片上传。
5. 上传失败不会清空当前草稿；已有提交、预览和删除行为不回归。

## 5. 非目标

- 不支持把远程网页图片 URL 自动抓取为附件。
- 不增加图片编辑、压缩、裁剪或 OCR。
- 不改变生产环境或执行部署。
