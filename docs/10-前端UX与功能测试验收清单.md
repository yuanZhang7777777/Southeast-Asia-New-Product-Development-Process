# 前端 UX 与功能测试验收清单

> 日期：2026-06-29  
> 状态：现行验收清单，已实现项用于开发环境业务回归。
> 范围：MVP 前段 `入池 -> 分配/自领 -> 销售认领/不认领 -> 主管审核 -> 出可备货清单`。

## 1. P0 必须修正

| 问题 | 验收口径 |
|---|---|
| 页面出现英文内部编码 | 节点、角色、状态、任务类型全部展示中文业务名 |
| F 列产品图片未展示 | 机会池、销售认领、主管审核都能看到商品图 |
| CH 备注截图未进入审核依据 | 主管审核页能看到备注文字、链接、截图/图片 |
| 不认领不出现在主管审核列表 | 认领和不认领都生成主管审核任务 |
| 主管审核信息不足 | 审核页展示商品图、主 SKU 组、子 SKU 明细、开品理由、认领/不认领内容、销售反馈、调研证据 |

## 2. P1 优先优化

| 问题 | 验收口径 |
|---|---|
| 主 SKU 组关系不清楚 | 组头展示主 SKU、开品理由、子 SKU 数；展开后展示子 SKU 图片、名称、SKU、类型 |
| 搜索能力不足 | 支持主 SKU、子 SKU、关键词、产品名称、站点、一级类目、销售员、状态搜索/筛选 |
| 分页不可用 | 默认页大小不低于 50，支持 20 / 50 / 100 / 200；翻页不丢搜索条件 |
| 分配建议过于简单 | 展示推荐原因，优先接入销售重点站点和主攻品类配置；主管-销售关系暂不作为第一版必要条件 |
| 认领表单依据不足 | 运营提交前能看到商品图、开品理由、竞品链接和已保存的平台调研图片；选品1 CC:CH 不进入业务表单 |

## 3. 导入测试

- 指定 `开发0623期` 导入，入池数量等于有效数据行数。
- 重复导入不产生重复数据。
- 无主 SKU 或无子 SKU 的行跳过。
- 来源文件、sheet、行号、原始快照可追溯。
- F 列 URL 图片和 Excel 内嵌图片都能进入平台。
- CG/CH 文本保留；CH 内嵌截图或图片可作为附件展示。

## 4. 机会池测试

- 列表展示站点、一级类目、关键词、产品图、主 SKU、子 SKU、产品名称、状态。
- 主 SKU 可成组展示，子 SKU 不被拆散。
- 搜索主 SKU、子 SKU、关键词、产品名称都能命中。
- 按站点、一级类目、状态、销售员筛选有效。
- 分页切换后筛选条件不丢失。
- 超过 200 条数据时仍能查全，不因前端固定截断导致漏数据。

## 5. 分配测试

- 按主 SKU 整组分配，同组子 SKU 不拆散。
- 选品1全部进入待分配池，源表 CD 不影响推荐或预分配。
- 候选销售为空、重复、无权限时给出明确提示。
- 改派必须填写原因并保留历史。
- 分配建议先按站点硬过滤，再按当前主 SKU 组负载均衡；重点品类、人员优先级和自定义顺序只处理同负载并列，主管-销售关系后续可选。
- “运营配置”入口必须紧邻“提交分配”并作为不可拆分的操作组；桌面、窄屏和统计文字变长时都不得彼此分行或被遮挡、裁切。
- 命令栏空间不足时按控件组自然换行，页面本身不得出现横向溢出。
- 运营负载为吸顶自适应网格；全部启用运营必须直接换行展示，负载区不得出现内部横向滚动，页面本身也不得横向溢出。
- 修改当前分配草稿后，对应运营的主 SKU 组数、子 SKU 数和“本次”数量立即更新。
- 运营配置支持同站点拖拽排序并保留上下按钮；跨站点拖拽不改变顺序，点击保存后刷新仍保持新顺序。
- 以初始负载相同的 3 名同站点运营和 7 个同类主 SKU 组回归，结果应为 `3/2/2`；提高其中一人的类目命中或 `assignment_priority` 不得让其独占任务。

## 6. 销售认领测试

- 已分配销售能打开自己的认领任务。
- 开放池机会可自领，认领后生成销售任务。
- 认领时认领单销必填。
- 不认领时不认领原因必填。
- 运营能看到产品图片、开品理由、竞品链接和自己上次提交的调研图片；选品1源表 CC/CG/CH 不预填。
- 普通认领列表中，`已填写未提交`紧邻单行提交按钮；商品详情矩阵不逐行显示该标签，统一由顶部“提交本主 SKU 未提交项（N）”反馈数量。已提交内容修改后必须计入未提交数量。
- 商品详情的上一组/下一组位于矩阵下方正常文档流，不悬浮遮挡表格，也不要求回到原点击位置收起。
- 不认领原因使用定制弹层，不改变矩阵行高和列宽；点击完成才写回，取消、右上角关闭、遮罩或 Esc 均放弃未确认改动。
- `不认领 -> 认领 -> 不认领`往返切换时，原不认领原因不丢失。
- 提交后页面展示中文状态，不出现内部编码。

## 7. 不认领审核测试

- 销售提交不认领后，主管审核列表必须出现该任务。
- 主管能看到不认领原因、销售反馈总结、备注、CH 截图/附件、商品图和竞品链接。
- 主管确认不认领后，该机会不进入可备货清单。
- 主管退回补充后，销售能重新提交。
- 主管改派时，原任务关闭，新任务生成，历史可追溯。

## 8. 主管审核测试

- 主管审核列表同时包含认领和不认领提交。
- 认领审核页展示认领单销和可备货量计算依据 `认领单销 * 30`。
- 审核通过后进入可备货清单，不自动生成采购/备货内部任务。
- 驳回或退回补充有原因记录。
- 审核记录可追溯到人、时间、意见和源数据。

## 10. 子 agent / 自测要求

- 每次实现前，先用本清单拆出 P0/P1。
- Codex 实现完成后必须自测导入、列表、认领、不认领、审核、导出路径。
- 子 agent 做只读功能测试，重点检查页面是否仍出现英文编码、图片证据是否缺失、不认领是否漏审、搜索分页是否实际可用。
- 回报时必须列出：修改文件、验证命令、手工测试路径、仍未实现项。
