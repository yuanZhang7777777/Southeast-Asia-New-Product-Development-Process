## 1. 第一版冻结范围

第一版已经确认冻结为：

```text
两张内部反馈表导入
  -> 主管一键分配 / 调整分配
  -> 运营认领或不认领
  -> 主管复核
  -> 运营填写 / 提交备货申请
  -> 主管勾选导出 Excel
```

第一版不做：

- 在线表自动写回入口。
- 中间桥 / 采购 / 供应链 / 下单待办。
- 匹配异常清单流程。
- 选品3、选品4、直发转海外仓、老品的正常导入入口；一次性历史只读迁移不在此限制内。
- 钉钉待办。

正式备货申请按 A-P 共 16 列导出；字段顺序、业务校验和 ERP 体积降级的唯一业务真源见 `docs/2026-07-09-已确认需求记录.md`。服务端计算备货数量、货值和总体积，保存最终申请快照及体积来源，主管不能代填运营申请；开发部署已支持填写长 / 宽 / 高（cm），并由服务端重新计算单个体积。

`新品中央字段导出`：

- 行粒度：当前 `submitted + waiting_export` 的子 SKU 申请，加上已确认不认领的追溯行。
- 字段：中央表 A-CB 共 80 个字段（包含 `开发是否接受核价结果`）+ 平台认领/复核/导出字段。
- 用途：领导查看和追溯，不是在线表写回。

导出边界：

- 当前开发部署 `cced0b9-listing-add-metrics-20260724_133848` 的正式备货导出只处理主管勾选的已提交申请；按业务期重复导出仅作为历史行为保留在旧版本记录中。
