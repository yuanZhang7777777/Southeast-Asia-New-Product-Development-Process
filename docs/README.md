## 维护规则

1. 新确认业务规则只更新 `2026-07-09-已确认需求记录.md`；未确认事项写入 `21`，不得另建临时需求文档。
2. 功能实现、验证或废弃只更新 `02`；推进顺序变化只更新 `20`。
3. 数据模型和 API 只更新 `04`；部署、环境变量、备份和回滚只更新 `06`。
4. `19` 只维护钉钉技术接入，发送对象和时间等业务节奏引用确认需求，不复制第二份规则。
5. `AGENT_HANDOFF.md` 只保留接手者立即需要的最新事实，不把它写成历史变更日志。
6. 归档目录默认只读。现行口径与归档冲突时，以确认需求及用户最新明确指令为准。
7. 不提交账号、密码、Cookie、Token、真实 `.env` 或其他秘密。
