## 当前最新标准速查

- 角色只保留 `运营`、`主管`、`超级管理员`；没有 `销售` 角色。
- 选品1业务期统一为 `开发MMDD期`，财根拆分期为 `开发MMDD期-财根`；历史可见范围以 `AGENT_HANDOFF.md` 的当前环境读回为准。
- 选品1标准支持 `一级类目` 和 `二级类目`；旧历史没有二级类目就留空，不补猜。
- 选品2是独立来源，期数命名为 `选品2-财根MMDD期`；`SPU=主SKU`、`SKU=子SKU`、站点固定 `PH`、类目为空。
- 历史认领只恢复 `认领` / `不认领` 事实、单销、拒绝理由、反馈、附件和来源行；不创建二调、刊登、观察、钉钉卡片。
- PLM 只确认到货事实；FineBI 只确认 `店铺 + Item + 周期` 的刊登和指标事实。
- 分配推荐优先 `一级+二级` 命中，其次一级命中；无类目时按启用运营负载均衡，同一主 SKU 组不拆散。

6. 归档目录默认只读。现行口径与归档冲突时，以确认需求及用户最新明确指令为准。
7. 不提交账号、密码、Cookie、Token、真实 `.env` 或其他秘密。
