销售自选 / 备货申请会读取以下五项服务器环境变量；只允许写入各环境独立的 `.env`，不得写入 Git、部署包、日志或文档：


五项中任一缺失、查询失败或尺寸不完整时，接口必须返回“需要手填”而不是泄露配置或阻断整个申请。当前开发部署允许填写长、宽、高（cm），由前后端计算体积并记录来源 `manual`。2026-07-22 只读预检确认开发环境仍未提供这五项，引用的资产文档也没有可唯一定位的精确凭据；不得猜测或写入 `.env`，真实 ERP 查询待实际凭据安全配置后再验收。

注意：`deploy/Caddyfile` 是只读 bind mount。宿主机使用 `sed -i`、覆盖复制等会替换 inode 的操作后，运行中的 Caddy 容器可能仍看到旧文件。无重启切流时应把宿主机持久配置通过标准输入加载，并从 Caddy Admin API 回读实际 upstream；不能只检查宿主机文件：

```bash
docker exec -i hengzhe-new-product-reverse-proxy-1 \
  caddy validate --config - --adapter caddyfile < deploy/Caddyfile
docker exec -i hengzhe-new-product-reverse-proxy-1 \
  caddy reload --config - --adapter caddyfile < deploy/Caddyfile
docker exec hengzhe-new-product-reverse-proxy-1 \
  wget -qO- http://127.0.0.1:2019/config/
```

7. 检查迁移版本、容器健康、API 健康、首页和关键接口。
8. 写入 `DEPLOYED_COMMIT`，并保留发布包和数据库备份用于回滚。
