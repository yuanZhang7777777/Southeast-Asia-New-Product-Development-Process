## 5. 选品2站点回查实测

`选品2：海外仓财根团队开发新品认领-反馈.xlsx` 最新 `5.26期` 本身未发现站点字段，但可用 SKU 回查中央新品表：

- 实测范围：`5.26期` 共 20 个 SKU。
- 匹配结果：20 个 SKU 全部能在 `东南亚海外仓新品表-PH.xlsx` 的 `5.26` sheet 找到唯一行；未匹配到 TH / VN。
- 中央表匹配字段：主要命中子 SKU 列；主 SKU 与子 SKU 相同的记录可能同时命中主 SKU 和子 SKU 单元格，但仍是同一行。
- 中央表站点：匹配行 `A` 列为 `菲律宾`。
- 中央表填写方式：`集团一部 / Shopee平台` 下，`销售员1 / 仔云` 列保存实际销售员姓名，`预估单销 / 仔云` 列保存认领单销；不认领时预估单销通常为 `0`。`合计单销` 不作为平台写回目标，由在线表公式或人工维护。

导入规则：

1. 如果选品2源表没有站点字段，先按源表 sheet 批次和 SKU 到 `东南亚海外仓新品表-PH/TH/VN` 对应 sheet 回查。
2. 如果精确匹配到唯一中央表行，站点采用中央表行内站点。
3. 如果匹配不到或匹配到多个中央表行，第一版不做异常清单、不推主管；该记录仍可参与平台认领和导出，中央表 / 财根桥由外部人工处理。

## 8. 市场监控表实测

- 文件：`【市场监控】海外仓精品市场调研.xlsx`。
- 定位：备货申请导出之后持续跟进的市场监控 / 二次调研工作表，不是 PLM 原始表，也不是备货申请表。
- Sheet：`说明`、`PH精品`、`TH精品`、`VN精品`、`MY精品`；其中 `MY精品` 当前为空。
- 国家 sheet 结构：`PH精品`、`TH精品`、`VN精品` 表头在第 2 行，列到 `AZ`，结构基本一致。
- 当前本地文件实测：`AO=产品定位（引流款/利润款/淘汰款）`，`AQ=6.22号公司:单销`。截图或在线表版本可能有列号漂移，后续导入 / 同步必须按表头匹配。
- 运营 / 销售填写或确认字段：销售备注、认领单销、首次调研结论、二次调研时间、二次竞对链接、二次调研结论、产品定位。
- 系统 / PLM 优先带出或辅助带出字段：到货通知、公司单销、海外仓在途、海外仓可发、公共池库存、首次上架时间、产品定义、预计到港时间、集团八部单销 / 在途 / 可发。
- 说明 sheet 原始规则：已到货产品若市场趋势不好 / 价格无优势，应及时清仓处理，并填写产品定位为淘汰款，避免智能采购根据清仓单销持续补货。
