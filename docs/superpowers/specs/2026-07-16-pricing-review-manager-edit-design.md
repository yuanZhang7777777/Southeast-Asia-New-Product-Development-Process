# 价格字段、主管复核与商品编辑设计

## 已确认需求

- 选品 1 导入继续使用用户选择的 Sheet；字段优先按两行表头识别，历史列位只作兜底。
- `稳定期定价`、`稳定期利润率`归入商品详情的“价格参考”；利润率按百分比展示。
- 价格、销量、单销等业务数字最多展示两位小数，不修改数据库原始精度。
- 主管复核按“运营认领待复核 / 运营不认领待复核”筛选；同一次多选只能包含一种类型。
- 批量通过：认领项进入通过认领，不认领项进入确认不认领。
- 批量拒绝：两种类型都退回运营补充，并要求统一退回原因。
- 主管可编辑商品现有业务字段、导入参数和现有工作流状态；来源文件、Sheet、行号、导入批次、审计记录保持只读。

## 数据与接口

- 修正定价字段别名：本期首个 Sheet 中稳定期定价实际为 `AJ`，稳定期利润率实际为 `AM`；`AQ/AR` 是稳定期/推广期总成本。通过表头匹配兼容新旧列位。
- 扩展现有商品 `PATCH`，接受允许列表内的工作流状态和按 Excel 列号提交的源参数改动。原始 `SourceRecordSnapshot` 不改，当前商品快照和审计日志记录运营修改。
- 批量复核使用单个后端事务；后端再次校验所选商品状态一致，防止前端绕过限制后混合提交。

## 界面

- 价格参考显示稳定期定价、稳定期利润率及现有价格/毛利字段。
- 主管商品编辑沿用当前编辑面板，增加状态下拉框和原生折叠区“其他导入参数”。
- 复核页使用两段筛选；筛选切换时清空选择。当前筛选结果支持全选、批量通过、批量拒绝。

## 验证

- 导入测试覆盖本期 `AJ/AM` 表头和旧表兼容。
- 后端测试覆盖商品字段/状态编辑、非法列和混合类型批量复核拒绝。
- 前端测试覆盖百分比/小数格式及复核筛选选择规则。
