# 运营认领 UAT 易用性修复设计

> 确认日期：2026-07-21
>
> 适用范围：导出中心、运营认领商品详情
>
> 环境边界：仅开发分支和开发环境 `139.224.2.166:18081`；不连接、不部署、不重启生产服务器

## 1. 背景与目标

本轮开发环境 UAT 暴露出四个界面问题：导出中心的“查看明细”按钮重复、详情矩阵中的提交状态标签会撑大编辑区、上一组/下一组悬浮在表格两侧、不认领原因展开后会改变表格结构。

本轮只修复以上实际问题，不改变现有业务状态流转。运营提交后、主管复核前仍可修改；主管退回补充后仍可修改；主管复核通过或确认不认领后不再进入运营认领可编辑列表。生产部署提交 `b373d65` 与当前开发分支在这一规则上一致，不需要从生产回迁代码。

## 2. 采用方案

采用最小局部修复，不重做认领页面，不新增组件库、数据库字段或接口。

### 2.1 导出中心

- 删除每个业务期数行中的“查看明细”按钮。
- 继续默认选择最新业务期数并在下方展示明细。
- 为保留多期切换能力，点击业务期数单元格或该期摘要行的非导出按钮区域即可切换下方明细。
- 两个导出按钮仍只导出所在业务期数；点击导出按钮不得额外触发行切换。

### 2.2 详情矩阵提交状态

- 从详情矩阵右侧编辑区移除逐行的`待填写 / 已填写未提交 / 已提交`标签，避免标签挤压、换行或改变矩阵宽度。
- 详情顶部继续用“提交本主 SKU 未提交项（N）”展示未提交数量，作为统一反馈和提交入口。
- 左侧子 SKU 固定列继续展示真实工作流状态；普通列表中的逐行状态提示和单行提交按钮保持不变。

### 2.3 上一组 / 下一组

- 移除详情两侧的绝对定位悬浮按钮及为其预留的左右空白。
- 在矩阵表格正下方增加正常文档流导航行：上一组靠左，下一组靠右。
- 第一组或最后一组继续显示对应禁用按钮，避免页面布局跳动。

### 2.4 不认领原因弹层

- 保留现有固定原因、多选、自定义原因、字符串格式及组内同步规则。
- 使用浏览器原生 `<dialog>` 提供遮罩、焦点约束和 Esc 关闭能力，但不使用浏览器默认视觉样式。
- 弹层外观复用项目现有颜色、字体、圆角、阴影、复选框和按钮样式；包含标题、右上角关闭、原因列表、自定义原因输入以及底部“取消 / 完成”。
- 弹层脱离表格布局，不改变行高、列宽或横向滚动结构。
- 打开弹层时以当前原因初始化临时选择；点击“完成”才写入当前浏览器草稿并关闭。
- 点击“取消”、右上角关闭、遮罩或 Esc 时放弃本次尚未确认的变化，保留打开弹层前的原因。
- 运营列表与商品详情继续复用同一个原因选择器。

## 3. 数据与流程边界

- 不修改认领、主管复核、备货导出、到货或后半段状态机。
- 不允许主管复核通过后的记录从运营认领页回改，避免与已经导出的备货数据冲突。
- 不迁移或改写开发库、生产库以及历史不认领原因。
- 不修改导出 Excel 字段、重复导出规则或导出审计。
- 不连接、不读取、不部署生产服务器；生产行为仅通过本地 `b373d65` 代码进行只读对照。

## 4. 验收标准

1. 导出中心不再显示“查看明细”，默认最新期明细仍可见，并可切换其他业务期数。
2. 详情矩阵填写或修改认领内容时，右侧编辑区宽度和表格结构不因提交状态标签变化。
3. 上一组和下一组位于矩阵下方同一行的左右两端，切换规则不变。
4. 不认领原因弹层打开、选择和关闭均不改变矩阵行高或列宽。
5. 弹层支持完成、取消、右上角关闭、遮罩和 Esc；固定多选及自定义原因重新打开后仍正确显示。
6. 运营提交后、主管复核前仍可修改；主管复核通过后按现有规则离开认领可编辑列表。
7. 前端相关单元测试、完整前端测试和生产构建通过。
8. 仅部署开发环境后，健康检查返回 `environment=development`，并继续使用现有 UAT 数据验证认领修改及后半段流程。

## 5. 非目标

- 不建设新的认领历史页、导出历史页或全屏认领编辑器。
- 不新增 UI 组件依赖。
- 不改变主管复核后的回改权限。
- 不部署、重启或修改生产环境。
